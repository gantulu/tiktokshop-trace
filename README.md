# TikTok Shop Order Tracker

Mobile-first order tracking and Admin dashboard built with React, TypeScript, Vite, and Supabase.

## Architecture

- Frontend persistence uses only Supabase Edge Functions.
- `get-tiktok` handles guest order lookup and authenticated Admin listing.
- `crud-tiktok-2` handles order creation, Admin updates, cancellation, and signed image-upload URL issuance.
- Order IDs are generated by the backend; clients must not provide them.
- Images are stored in the private `tiktok-order-images` Supabase Storage bucket.
- The browser uploads images with short-lived signed upload tokens. The service-role key is never exposed to the frontend.
- Admin sign-in uses Supabase Auth. Admin access requires a trusted `app_metadata.role` value of `admin` or `superadmin`.

## Configure

1. Install dependencies: `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to the project's public Supabase URL and anon/publishable key.
4. Never put `SUPABASE_SERVICE_ROLE_KEY` in a `VITE_*` variable or frontend file.
5. Start the app: `npm run dev`.

## Edge Functions

Deploy the functions from `supabase/functions`:

- `get-tiktok`
- `crud-tiktok-2`

The deployed project must have `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` configured as Edge Function secrets.

## Storage

Migration `supabase/migrations/20261101090000_tiktok_storage_bucket.sql` creates the private image bucket and adds image-path columns to `public.tiktok_orders`.

Allowed image types: JPEG, PNG, WebP. Maximum size: 5 MB.

## Customer order lookup

Customers must provide both the generated order ID and the recipient phone number. The API verifies both values before returning order details.
